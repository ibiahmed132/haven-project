**Welcome to Bounce no S’more! 🤗**

You play as Marshy the Marshmallow. Help him avoid the *evil* fire and join the ~~clouds~~ big sky-mallows.

**What did we make the game with?**

We made this game with Godot using music and assets that we made ourselves in BandLab and IbisPaint!

We also used some freely available assets, like trumpet fanfare from benkirb, and pixel art from Polar_34!

**How do I even run this thing?**

You can play it on [itch.io](https://ibiahmed130.itch.io/bounce-no-smore), no installs or anything!
